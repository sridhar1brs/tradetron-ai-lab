🛡️ Key Tradetron Rulebook Highlights
Core engine invariants enforced by tradetron_auditor.py to eliminate silent live trading failures.
Rule ID Title & Topic Engine Enforcement & Rationale Status
Rule 42 OHLC Keyword Nesting Close() in conditions MUST use Symbol(Instrument Name('NSE,NIFTY 50,,,,,')) — bare Instrument() resolves to None. ✓ Enforced
Rule 30 Qty Macro Formatting qtyType: "Lots" MUST use tt_lots(1,'INSTRUMENT','CE') — plain strings cause greyed-out Fx state with "Clear Fx". ✓ Enforced
Rule 31 Database Primary Key Positions legs MUST use integer DB keys (1855 for NIFTY 50, 1854 for BANK NIFTY). Strings cause blank dropdowns. ✓ Enforced
Rule 27 Spot LTP Comma Format Instrument Name parameters MUST contain 5 comma slots (NFO,NIFTY 50,,,,,). 4 commas break backend string parsing. ✓ Enforced
Rule 13 Math Operation Order Condition logic requires postfix parameter order: [Operand 1, Operand 2, Operator]. Operator cannot be in middle. ✓ Enforced
Rule 43 Simulator vs Auditor Gate Simulator evaluates intended Python logic; Auditor is the mandatory AST structural gate before Tradetron upload. ✓ Enforced
